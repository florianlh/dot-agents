Fresh clones & detached HEAD note: When cloning a repo with submodules (e.g., in a fresh agent VM), Git checks out .agents/ in a detached HEAD at the commit pinned by the parent repo. That works fine for read-only use; if you plan to edit and push changes inside .agents/, run git -C .agents switch main first.
